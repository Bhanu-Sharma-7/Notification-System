# 📐 Math Crush — Pastel Neo-Brutalist Mental Math Game

A 100% offline-first, engaging mental math calculation game built with **React Native**, **Expo SDK 58**, and **TypeScript**.

---

## 🎨 Aesthetic & Design Philosophy
- **Style:** Pastel Neo-Brutalist
- **Canvas Background:** Warm cozy cream (`#F5F2EB`)
- **Borders & Shadows:** Solid 2.5px solid `#18181B` with tactile unblurred drop-shadows
- **Palette:** Mint (`#70C1B3`), Soft Peach (`#FFE5D9`), Butter Yellow (`#FFE169`), Soft Coral (`#FFAAA6`), Lavender (`#E8EAFF`)
- **Typography:** Chunky display fonts (`LuckiestGuy` & `Bungee`)

---

## ✨ Features
1. **Dynamic Question Engine:** Infinite procedural arithmetic (+, -, ×, ÷, mixed) and advanced formulas (trigonometry, squares, square roots, cubes, percentages).
2. **Offline-First Persistence:** Daily active streaks, XP level progression, and category high scores saved locally via `AsyncStorage` (Zero server cost).
3. **Tactile Haptic Feedback:** Physical vibration feedback on correct/wrong answers and button presses via `expo-haptics`.
4. **Built-in Scratchpad Calculator:** Pop-up Pastel Neo-Brutalist calculator available directly in gameplay.
5. **Unlockable Trophies & Stats:** 6 achievement badges with detailed accuracy breakdowns.
6. **Monetization Ready:** Clean Pastel Neo-Brutalist AdMob banner wrapper placeholders.

---

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Start the dev server
```bash
npx expo start
```
Scan the QR code with **Expo Go (SDK 58)** on Android or iOS.
